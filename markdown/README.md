# Markdown Skills

Skills for the markdown documents a repository carries: readme, contributing guide, changelog and the conventions that keep them consistent across projects.

They are technology-agnostic. The same readme structure applies to a Flutter app, a Go service or a published package.

| Skill | Use it for |
| --- | --- |
| [markdown-readme](markdown-readme/) | Readme structure, header block, badges, multi-language versions |

## Boundaries

- How to use a project: `markdown-readme`
- How to work on a project: the repository's own CONTRIBUTING guide, which the readme links rather than restates
- Store listing text for a mobile release: `flutter-release-notes`
