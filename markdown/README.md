# Markdown Skills

Skills for the markdown documents a repository carries: readme, contributing guide, security policy, architecture document and the conventions that keep them consistent across projects.

They are technology-agnostic. The same readme structure applies to a Flutter app, a Go service or a published package.

| Skill | Use it for |
| --- | --- |
| [markdown-readme](markdown-readme/) | Readme structure, header block, badges, multi-language versions |
| [markdown-community-health](markdown-community-health/) | Contributing guide, security policy |
| [markdown-architecture-doc](markdown-architecture-doc/) | Architecture document, layering, non-obvious decisions |

## Boundaries

- How to use a project: `markdown-readme`
- How to set up and submit a change, report a vulnerability, or what behavior is expected: `markdown-community-health`
- Where a file belongs and why a layer exists: `markdown-architecture-doc`
- Store listing text for a mobile release: `flutter-release-notes`
